# Cleanup Findings

Status after the cleanup pass. The original findings were ordered by release
risk; each item below records whether it was fixed or explicitly accepted.

## P0 Release Blockers

1. **Resolved:** `bsc` package bin wrapper restored.

   `cli/bsc.js` is tracked again and `packages/artifacts.json` ships it, so the
   package `bin` entry has a real target.

2. **Resolved:** absolute local symlinks removed.

   The machine-local `compiler-rust/compiler-rust` and `packages/packages`
   links were removed from the release branch.

3. **Resolved:** machine-local build artifacts removed.

   Generated `lib/bs/*` files with local paths were deleted and the generated
   directory is ignored.

4. **Resolved:** unconditional `/tmp` debug writes removed from normal builds.

   Moregen debug file emission is now gated behind `RUST_DEBUG_MOREGEN`.

5. **Resolved:** deleted tagged-template helper restored.

   `tests/tests/src/tagged_template_lib.js` is tracked again, matching the test
   imports.

## P1 Must Review Before Beta

6. **Resolved:** generated snapshots and performance cache files removed.

   Generated test outputs and `.performance-cache/typechecker/*` were deleted
   from the branch and ignored.

7. **Resolved:** one-off migration scripts removed.

   The local `fix_boxing.py` and `compiler-rust/fix_*.py` scripts were deleted.

8. **Resolved:** GenType staged panic replaced with a controlled diagnostic.

   The reachable `unimplemented!` in `compiler-rust/src/gentype/main.rs` is now
   a fatal error path instead of a Rust panic.

9. **Resolved with documented invariants:** unsafe compiler cleanup reviewed.

   The raw-pointer `RaiseCounter` and its `unsafe impl Send/Sync` were removed
   from `compiler-rust/src/raw_lambda/matching.rs`. Remaining unsafe internals
   are narrowed to the type arena and centralized synthetic parse-arena append
   helpers with safety comments and OCaml reference locations.

10. **Resolved:** OCaml reference debug instrumentation removed from hot paths.

    Debug-only additions in `compiler/ml/ctype.ml`,
    `compiler/ml/typecore.ml`, and `compiler/ml/sexp_typedtree.ml` were removed.

11. **Resolved:** new parity/profile scripts made portable.

    New scripts use `scripts/platform.sh` or repo-relative defaults instead of
    hardcoded `darwin-arm64`, `/Users/jake/dev/tella-fusion`, or
    `/Users/jaapf/...` paths.

12. **Resolved for new scripts:** variable-based directory cleanup removed.

    New cleanup code now removes specific files and prunes known temporary
    directories with `rmdir`. Pre-existing cleanup commands outside this diff
    were intentionally left alone.

13. **Resolved:** duplicated symlinked package fixture restored.

    The fixture paths under `tests/build_tests/duplicated_symlinked_packages`
    are symlinks again, so the test still exercises symlink behavior.

## P2 Cleanup / Decision Items

14. **Resolved:** generated playground stdlib asset removed.

    `playground/public/stdlib.json` was deleted from the branch and ignored so
    it is generated by the playground build.

15. **Accepted:** `CLAUDE.md` remains a regular file.

    `AGENTS.md` stays canonical for repository-wide assistant rules. The
    regular `CLAUDE.md` file is intentionally kept as a Claude-specific entry
    point that points to `AGENTS.md` and repeats the extra OCaml-reference and
    commit-discipline reminders requested during this work.

16. **Accepted with comments:** rewatch telemetry and allocator kept.

    OTLP telemetry remains opt-in only when endpoint environment variables are
    supplied. The global `mimalloc` allocator is an intentional rewatch
    performance choice and is documented as separate from compiler parity.

17. **Resolved:** release `panic = "abort"` removed.

    `compiler-rust/Cargo.toml` no longer overrides release panics to abort.

18. **Resolved:** generated failure-category cache removed.

    `scripts/failure_categories.json` was deleted and ignored; it is generated
    by the categorization script.
