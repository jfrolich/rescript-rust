# Lowering reference experiments

Measured before changing the legacy lowering. The reference was built with
`eval $(opam env); dune build --root .`; the runtime with
`rescript build-reference --bsc <reference-bsc> packages/@rescript/runtime`.
Rust was built with `cargo build --manifest-path rewatch/Cargo.toml`.
Both compilers used the same runtime includes and ES module output.

Q2 emits no label in OCaml, not the predicted `loop_1`: the variant
dispatch becomes conditionals. Rust emits `loop_0`. Q5 becomes an outer
tail loop in OCaml but remains a recursive call in Rust.

## Q2

```rescript
type t = A | B(int) | C(int, int) | D
@val external log: int => unit = "log"
let h = (c, xs: array<t>) => if c {
  for i in 0 to Array.length(xs) - 1 {
    switch Array.getUnsafe(xs, i) {
    | A => break
    | B(n) => log(n)
    | C(n, m) => log(n + m)
    | D => log(4)
    }
  }
  1
} else { 2 }
```

## Q5

```rescript
let rec g = x => {
  let rec even = n => if n == 0 { true } else if n == 1 { false } else { even(n - 2) }
  if even(x) { g(x - 1) } else { x }
}
```

        _n = n - 2 | 0;
        continue;
      };
    };
    if (!even(x)) {
      return x;

    continue;
  };
}
