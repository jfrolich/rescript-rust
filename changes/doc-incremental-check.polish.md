- `rescript doc` (and `rescript-tools doc`) no longer type-checks the whole project with source locations on every call. It reads the build record and checks only what changed since the last build, then compiles with locations just the modules whose declarations it documents as items of another module. On a 3,700-module application, a call after a build takes 50 ms instead of 700 ms (140 ms for a file with an `include`), with the same JSON.
