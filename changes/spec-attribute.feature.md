- Add `@spec` and `Spec.t`: a `let` of type `Spec.t<state, action>` marked `@spec` names a state machine (its first state and its reducer) and what must be true of it (`always`, `sometimes`, `reachable`, `eventually`). A build type checks it and leaves it out of the JavaScript; `rescript verify` goes through every state the machine can get into and reports the shortest run that breaks a property. See `docs/verify/spec.md`.
