- `rescript-tools reanalyze` works again: builds write no `.cmt` files for it to read, so it runs `rescript reanalyze`, which type-checks the project without writing files and runs the dead code, exception and termination analyses on the Rust typed tree, printing the same reports. The options that read a directory of `.cmt` files (`-dce-cmt`, `-exception-cmt`, `-termination-cmt`, `-all-cmt`) still run the OCaml tool.
