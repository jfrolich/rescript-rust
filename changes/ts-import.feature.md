- Import TypeScript with `%ts`: `let {getUser} = %ts("./api.ts")`, `type user = %ts("./api.ts#User")` and `module Api = %ts("./api.ts")` declare the values, types and classes of a TypeScript module with types read from the TypeScript checker, which is linked into the compiler. Rust compiler only.
- Declare a class on a private record with `@instanceOf`, name its superclass with `@extends(: parent)`, and import the class with `@module` beside `@instanceOf`; such records are untagged variant cases, tested subclass first, and upcast with `:>`. Rust compiler only.
- An `@unboxed` variant can have several cases whose payload is a record, and one open object case, when a field tells them apart: the compiler tests a field with `"f" in x`, `x.f === literal` or `typeof x.f`. Rust compiler only.
- Cases of a tagged variant whose payload is an inline record can share a tag (`@as("Literal") StringLiteral({value: string}) | @as("Literal") NumericLiteral({value: float})`): the `switch` on the tag tells them apart inside its arm by their other fields, as object cases are. `%ts` imports a union whose members share a tag this way. Rust compiler only.
