- `as`, `constraint`, `exception`, `external`, `mutable`, `of`, `open`, `private`, `rec` and `when` are contextual keywords: each is a keyword only where the grammar uses it and a name everywhere else, so `let open = dialog.open`, `{...dialog, open}`, `(~as) => as` and `exception => log(exception)` need no escape. An escaped spelling such as `\"open"` placed directly where the keyword goes now reads as the keyword; write the name in parentheses there instead. The formatter prints these names bare and adds parentheses where the bare name would read as the keyword.
