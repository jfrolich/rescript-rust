- `rescript` (the Rust build system) moves to the flat `lib/rescript` as well: its build state is `lib/rescript/rescript.sqlite` and its locks are `lib/rescript/build.lock` and `lib/rescript/watch.lock`; a `lib/bs` or `lib/ocaml` makes the next build clean the package, which removes them. It still writes no `.cmi`/`.cmt`, `compiler-info.json` or `.sourcedirs.json` (editor tooling reads them from a running watcher), and the runtime's sources are read from the root of `@rescript/runtime`.
